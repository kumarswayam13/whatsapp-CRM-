# WhatsApp CRM Platform

> **A modern, AI-powered WhatsApp CRM and Marketing Platform built for businesses to automate customer communication, sales, support, and marketing.**

> **Note:** This repository is intended to showcase the project. The complete source code is proprietary and is **not** publicly available.

---

## Overview

This project is a full-featured WhatsApp CRM platform designed to help businesses manage customer conversations, automate workflows, run marketing campaigns, and integrate WhatsApp into their daily operations.

It supports both the **Official WhatsApp Business API** and QR-based WhatsApp connections, making it suitable for startups, agencies, SMEs, and enterprises.
